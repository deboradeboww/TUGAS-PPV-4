# 📝 App Manajemen Tugas & Jadwal Kuliah (TUGAS-PPV-4)

Aplikasi web interaktif (*Single Page Application*) berbasis **HTML, CSS, dan JavaScript Vanilla** yang dirancang untuk membantu mahasiswa mengelola daftar tugas, jadwal kuliah, serta catatan cepat (*sticky notes*) harian.

---

## 🚀 Fitur Utama

1. **Dashboard & Form Tugas**:
   - Input tugas lengkap dengan kategori mata kuliah, *deadline*, tingkat prioritas, dan status.
   - Validasi input waktu nyata (*real-time validation*) untuk mencegah pengiriman data kosong.
2. **Daftar Tugas & Filter**:
   - Filter tugas berdasarkan Kategori dan Status pengerjaan.
   - Fitur ubah status cepat, edit tugas via *Pop-up Modal*, dan *Progress Bar* kelengkapan tugas otomatis.
3. **Jadwal Kuliah Interaktif**:
   - Tampilan tabel jadwal mingguan yang tertata rapi.
   - Modal interaktif untuk mengubah data jam, mata kuliah, dan ruang kelas.
4. **Catatan Cepat (*Sticky Notes*)**:
   - Pilihan 6 variasi warna latar catatan.
   - Fitur **Pin (Sematkan)** untuk memprioritaskan catatan penting ke posisi paling atas.
5. **Responsif & Aksesibel**:
   - Tampilan yang nyaman diakses melalui perangkat desktop maupun *mobile/smartphone*.
   - Notifikasi *Toast* animasi saat aksi berhasil dilakukan.

---

## 🛠️ Teknologi yang Digunakan

* **HTML5**: Struktur semantic web dan formulir input.
* **CSS3**: Layouting (Flexbox & Grid), Variabel CSS, Animasi/Transisi UI.
* **JavaScript (ES6+)**: DOM Manipulation, State Management, Event Handling.
* **Font Awesome v6**: Ikon antarmuka interaktif.
